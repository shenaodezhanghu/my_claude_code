# 第七章 管理上下文与大工具结果

> 本章直接从第六章完成后的代码继续修改。代码不会同时保留“旧截断”和“新持久化”两条路径；本章完成后，工具结果只能按照“完整执行结果 → 持久化 → 截断预览”的顺序处理。

## 7.1 为什么需要这一章

第六章结束时，Agent 已经能够安全地调用工具。但是运行时间变长后会出现两个问题：

1. `read_file`、`grep_search` 和 `run_shell` 可能一次返回大量文字。
2. `self.messages` 会随着模型回复和工具结果不断增长。

如果工具结果在 Registry 中先被截断，后面保存到磁盘的也只是残缺内容。因此必须先取得完整结果，再决定如何放进上下文。

本章最终数据流如下：

```text
工具执行
  → ToolRegistry 返回完整字符串
  → 超过 30 KB 时把完整结果保存到项目目录
  → 生成包含保存路径的预览
  → 对准备加入 messages 的文字做 50,000 字符兜底截断
  → messages 过长时总结旧回合
  → 调用模型
```

## 7.3 第一步：删除 Registry 中的旧截断

打开 `mini_claude/tools/registry.py`，删除下面两项：

```python
MAX_RESULT_CHARS = 50_000
```

```python
def truncate_result(result: str) -> str:
    ...
```

不要把它们保留成“以后可能使用”的死代码。截断职责已经移到本章的 `context.py`。

`execute()` 最终只负责查找工具、执行工具、处理异常和统一返回类型：

```python
def execute(
    self,
    name: str,
    arguments: dict,
    context: ToolContext,
) -> str:
    tool = self.get(name)
    if tool is None:
        return f"Error: unknown tool: {name}"

    try:
        result = tool.run(arguments, context)
    except Exception as exc:
        result = f"Error: {type(exc).__name__}: {exc}"

    return result if isinstance(result, str) else str(result)
```

完成这一步以后，Registry 中不再存在任何结果长度限制。

## 7.4 第二步：创建 context.py

创建 `mini_claude/context.py`：

```python
from __future__ import annotations

from datetime import datetime
from pathlib import Path


LARGE_RESULT_BYTES = 30 * 1024
MAX_RESULT_CHARS = 50_000
PREVIEW_LINES = 200
COMPACT_TRIGGER_CHARS = 80_000
KEEP_RECENT_TURNS = 3


def truncate_result(result: str) -> str:
    if len(result) <= MAX_RESULT_CHARS:
        return result

    keep_each = (MAX_RESULT_CHARS - 80) // 2
    omitted = len(result) - keep_each * 2
    return (
        result[:keep_each]
        + f"\n\n[... truncated {omitted} characters ...]\n\n"
        + result[-keep_each:]
    )


def persist_large_result(
    tool_name: str,
    result: str,
    project_root: Path,
) -> str:
    """先保存完整结果，再返回适合进入上下文的文字。"""
    size = len(result.encode("utf-8"))

    if size <= LARGE_RESULT_BYTES:
        return truncate_result(result)

    result_dir = project_root / ".mini-agent" / "tool-results"
    result_dir.mkdir(parents=True, exist_ok=True)

    timestamp = datetime.now().strftime("%Y%m%d-%H%M%S-%f")
    result_file = result_dir / f"{timestamp}-{tool_name}.txt"
    result_file.write_text(result, encoding="utf-8")

    lines = result.splitlines()
    preview = "\n".join(lines[:PREVIEW_LINES])
    relative_path = result_file.relative_to(project_root)

    context_result = (
        f"[Result too large: {size / 1024:.1f} KB, "
        f"{len(lines)} lines. Full output saved to {relative_path}. "
        "Use read_file when the complete result is needed.]\n\n"
        f"Preview:\n{preview}"
    )
    return truncate_result(context_result)
```

这里的先后顺序不能交换：

```text
result_file.write_text(result)   # 保存完整结果
        ↓
生成 preview
        ↓
truncate_result(context_result)  # 只截断交给模型的预览
```

## 7.5 第三步：统一 Agent 的工具结果处理入口

在 `agent.py` 顶部增加：

```python
from mini_claude.context import persist_large_result
```

在 `MINI_CLUE_AGENT` 中增加：

```python
def _execute_tool(self, name: str, arguments: dict) -> str:
    full_result = self.tools.execute(
        name,
        arguments,
        self.tool_context,
    )
    return persist_large_result(
        name,
        full_result,
        self.tool_context.project_root,
    )
```

然后在权限判断中，把两处：

```python
self.tools.execute(name, arguments, self.tool_context)
```

全部替换为：

```python
self._execute_tool(name, arguments)
```

这里不是保留两个入口。替换完成后，`chat()` 中不应再直接出现 `self.tools.execute(...)`。

权限顺序仍然是：

```text
权限检查 → 用户确认 → 执行工具 → 处理完整结果
```

被拒绝的工具不能执行，也不会产生结果文件。

## 7.6 第四步：实现安全的历史压缩

继续在 `context.py` 中增加：

```python
def history_size(messages: list[dict]) -> int:
    return len(str(messages))


def find_recent_boundary(
    messages: list[dict],
    keep_turns: int = KEEP_RECENT_TURNS,
) -> int:
    user_indexes = [
        index
        for index, message in enumerate(messages)
        if message.get("role") == "user"
        and isinstance(message.get("content"), str)
    ]

    if len(user_indexes) <= keep_turns:
        return 0
    return user_indexes[-keep_turns]


def render_for_summary(messages: list[dict]) -> str:
    lines: list[str] = []

    for message in messages:
        role = str(message.get("role", "unknown"))
        content = message.get("content")

        if isinstance(content, str) and content:
            lines.append(f"{role}: {content}")
        elif message.get("tool_calls"):
            names = [
                call.get("function", {}).get("name", "unknown")
                for call in message["tool_calls"]
            ]
            lines.append(
                f"assistant requested tools: {', '.join(names)}"
            )
        else:
            lines.append(f"{role}: [structured message]")

    return "\n".join(lines)


def summarize_messages(
    messages: list[dict],
    client,
    model: str,
) -> str:
    transcript = render_for_summary(messages)
    response = client.chat.completions.create(
        model=model,
        messages=[
            {
                "role": "system",
                "content": (
                    "总结 Coding Agent 的历史。保留用户目标、关键决定、"
                    "文件路径、已完成修改、错误、验证结果和待办事项。"
                    "不要虚构未执行的操作。"
                ),
            },
            {"role": "user", "content": transcript},
        ],
    )
    return response.choices[0].message.content or "无可用摘要"


def maybe_compact(
    messages: list[dict],
    client,
    model: str,
) -> list[dict]:
    if history_size(messages) < COMPACT_TRIGGER_CHARS:
        return messages

    boundary = find_recent_boundary(messages)
    if boundary == 0:
        return messages

    older = messages[:boundary]
    recent = messages[boundary:]
    summary = summarize_messages(older, client, model)

    print(f"(已将 {len(older)} 条旧消息压缩为摘要)")
    return [
        {
            "role": "user",
            "content": f"[Earlier conversation summary]\n{summary}",
        },
        {
            "role": "assistant",
            "content": "已了解此前摘要，将根据最近任务继续。",
        },
        *recent,
    ]
```

不能直接使用 `messages[-6:]`。OpenAI 工具调用必须保留完整配对：

```text
assistant(tool_calls=[...])
tool(tool_call_id=...)
```

从普通用户消息的边界开始保留，可以避免切断这组关系。

## 7.10 本章最终状态

第七章完成后，项目中只能存在下面这一条结果路径：

```text
ToolRegistry.execute() 返回完整结果
→ MINI_CLUE_AGENT._execute_tool()
→ persist_large_result()
→ 完整落盘或直接返回
→ 截断上下文文字
→ 写入 role="tool" 消息
```

不存在 `execute_raw()`，不存在 Registry 提前截断，也不存在新旧两套结果处理函数。第八章将在这个最终状态上增加跨会话记忆。
