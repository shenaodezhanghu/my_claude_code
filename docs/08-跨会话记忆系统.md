# 第八章 构建跨会话记忆系统

> 本章的起点就是第七章完成后的代码。第七章的大结果持久化、权限检查、上下文压缩和流式调用已经是 Agent 的组成部分，本章不重新实现它们，也不保留第七章之前的旧调用方式；这里只在第七章最终版上增加记忆召回。

## 8.1 为什么 Session 还不够

Session 保存某一次会话的完整消息，必须通过 `--resume <session-id>` 才能恢复。新会话不会自动知道旧会话中的重要事实。

Memory 只保存少量、跨会话仍然有价值的内容，例如：

- 用户偏好的回答方式。
- 项目的部署约定。
- 无法直接从当前代码推导出的决定。

本章沿用原教程的最小逻辑：Markdown 文件保存记忆，关键词重叠计算相关度，最多召回三条，然后追加到本轮 System Prompt。

```text
.mini-memory/*.md
  → 读取记忆
当前用户问题
  → 提取关键词
  → 计算重叠数量
  → 取 Top 3
  → 追加到 System Prompt
  → 调用模型
```

## 8.3 第一步：创建 memory.py

创建 `mini_claude/memory.py`：

```python
from __future__ import annotations

import re
from pathlib import Path


def extract_keywords(text: str) -> set[str]:
    lowered = text.lower()

    english = {
        word
        for word in re.findall(r"[a-z0-9_]+", lowered)
        if len(word) > 2
    }

    chinese_chars = re.findall(r"[\u4e00-\u9fff]", lowered)
    chinese = {
        "".join(chinese_chars[index:index + 2])
        for index in range(len(chinese_chars) - 1)
    }

    return english | chinese


def recall_memories(query: str, project_root: Path) -> str:
    memory_dir = project_root / ".mini-memory"
    if not memory_dir.is_dir():
        return ""

    query_words = extract_keywords(query)
    if not query_words:
        return ""

    scored: list[tuple[int, str]] = []

    for path in memory_dir.glob("*.md"):
        try:
            text = path.read_text(encoding="utf-8").strip()
        except OSError:
            continue

        score = len(query_words & extract_keywords(text))
        if score > 0:
            scored.append((score, text))

    if not scored:
        return ""

    top_memories = sorted(
        scored,
        key=lambda item: item[0],
        reverse=True,
    )[:3]

    content = "\n".join(
        f"- {text}"
        for _, text in top_memories
    )

    return (
        "\n\n# Memory\n"
        "以下是与当前问题相关的长期记忆。"
        "记忆可能已经过时，涉及当前代码状态时必须使用工具核实。\n"
        f"{content}"
    )
```

原教程使用确定性的关键词重叠，不调用模型，也不使用向量数据库。这里增加中文双字片段只是为了让中文问题也能按照相同原理匹配。

stream = self.client.chat.completions.create(

## 8.6 第四步：修改重试调用

第七章的 `chat()` 中原来是：

```python
result = with_retry(self._call_model_stream)
```

因为 `_call_model_stream()` 现在需要本轮用户问题，所以把这一行替换为：

```python
result = with_retry(
    lambda: self._call_model_stream(user_text)
)
```

不要保留原来的 `with_retry(self._call_model_stream)`，否则调用时会缺少参数。

完成修改后，`chat()` 开头应该是下面这个连续流程：

```python
def chat(self, user_text: str) -> str:
    self.messages.append({"role": "user", "content": user_text})

    while True:
        self.messages = maybe_compact(
            self.messages,
            self.client,
            self.model,
        )

        result = with_retry(
            lambda: self._call_model_stream(user_text)
        )
        message = result.message
        self.messages.append(message)

        tool_calls = message.get("tool_calls") or []
        if not tool_calls:
            return str(message.get("content") or "")

        # 后面继续使用第七章完成后的权限检查、
        # self._execute_tool() 和 role="tool" 消息逻辑。
```

这里没有新建第二套 Agent Loop。`maybe_compact()`、流式请求、工具权限和 `_execute_tool()` 都继续位于同一个循环中。

## 8.7 保存新记忆

本章不新增 `save_memory` 工具。Agent 已经拥有 `write_file`，因此当用户明确要求“记住”时，可以把事实写入 `.mini-memory/*.md`。

在 `STATIC_PROMPT` 的工作规则中增加：

```text
只有当用户明确要求记住某个跨会话仍有价值、且不能直接从当前代码推导的事实时，才允许把简短 Markdown 写入 .mini-memory/。不要保存 API Key、密码、Token 或临时任务细节。
```

如果目标记忆文件已经存在，仍然遵守前面章节建立的 read-before-edit：先读取，再修改。这里复用 `write_file` 和 `edit_file`，不再注册功能重复的记忆写入工具。

## 8.8 Session 与 Memory 的关系

```text
Session
├── 保存完整的 user / assistant / tool 消息
├── 使用 --resume <session-id> 恢复
└── 位于用户目录 .mini-agent/

Memory
├── 保存筛选后的长期事实
├── 新会话也会按当前问题召回
└── 位于项目目录 .mini-memory/
```

Memory 不替代 Session，Session 也不能整份塞进 System Prompt。二者进入 Agent 的位置不同，因此不会形成两套对话历史。

## 8.10 本章最终状态

完成第八章后，一次模型调用的唯一流程是：

```text
收到 user_text
→ 写入 self.messages
→ maybe_compact() 压缩过长历史
→ build_system_prompt()
→ recall_memories(user_text) 追加相关记忆
→ _call_model_stream() 调用百炼
→ 若有工具请求，先检查权限
→ _execute_tool() 获取完整结果并处理大结果
→ 工具结果写回 self.messages
→ 继续同一个 Agent Loop
```

第八章没有删除第七章的能力，也没有保留第七章之前的旧实现。它是在同一个 Coding Agent 上增加了一层跨会话记忆。
