# 从零手写 Mini Claude Code（Python + 阿里云百炼）

这套教程面向希望真正动手实现 Coding Agent 的学习者，并与当前 `myclaude/myclaude/mini_claude` 代码同步：从一次普通模型调用开始，逐步实现工具调用、Agent Loop、系统提示词、命令行会话以及后续高级能力。

这是一套累进式教程。第 N 章必须以第 N-1 章完成后的代码为唯一开始状态；出现“替换”时要删除旧实现，不能为了兼容同时保留新旧两条路径。前一章已经完成的能力会成为 Coding Agent 的组成部分，后一章只在同一个 Agent 上继续增加能力。

教程的组织方式参考《第十五章 构建赛博小镇》：每章先说明要解决的问题，再给出架构、项目结构、完整的分步实现、运行验证、理解检查与总结。代码逻辑则严格按照本仓库 Python 版本的演进顺序讲解。

## 每章的正确学习方法

每一章都执行以下流程：

1. 只阅读“目标”和“架构”，先形成自己的实现思路。
2. 在 `myclaude/myclaude` 中亲手输入代码，不要整段复制。
3. 运行本章验证任务。
4. 阅读代码解析，解释每条消息为什么要加入历史。
5. 使用原仓库的章节演示对照结果，例如 `node steps/run.mjs 1 --py`。
6. 完成本章练习后再进入下一章。

## 教程依据与改写原则

本教程主要依据当前仓库中的 `docs/00`～`docs/15`、Python 最终实现和逐章快照编写，同时参考项目在线文档的讲解顺序。为适配阿里云百炼，API 示例使用 OpenAI 兼容格式；Agent Loop、工具状态、上下文、记忆和权限机制仍与原项目对应。

每章遵循三条原则：

1. 先展示为什么需要该能力，再写代码。
2. 代码必须能与上一章连续演进，不能只给互不相干的片段。
3. 明确区分本章实现、后续章节能力和生产级扩展，避免提前堆叠复杂抽象。

### 全教程统一代码约定

从第一章开始，所有章节统一使用：

```text
包名               mini_claude
Agent 类           MINI_CLUE_AGENT
模型函数           get_models()
工具目录           mini_claude/tools/
工具抽象           Tool
工具注册与分发     ToolRegistry
工具会话状态       ToolContext
Schema 获取        self.tools.schemas()
工具执行           self.tools.execute(...)
练习工作目录       myclaude/myclaude
```

教程不再先讲一套 `tools.py` 分发函数、下一章再整体推翻。第一章用同一架构注册 `read_file`，第二章继续注册其余工具，03、04 章只扩展提示词和会话能力。
